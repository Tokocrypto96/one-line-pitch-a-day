> "You've carried that app idea for months, so describe it in one sentence and let an AI agent on make.fun start building the first version tonight, free, while you watch — and if you don't love it, you've lost nothing at all."

The pitch leans on what the friend already has — an idea they've carried for months — and lowers the risk to zero: describe it in one sentence, watch the first version being built tonight for free, and walk away having lost nothing if they don't love it.

## Run it

```sh
python3 main.py
```

This writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3 standard library only, offline, deterministic — no network, no extra output files.
